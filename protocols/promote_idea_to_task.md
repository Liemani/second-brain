# Promote Idea to Task

An idea becomes a task when it is ready to be executed as a concrete work item.

## Purpose

Move an idea from a speculative state into an executable task.

## Conditions

- The idea is specific enough to act on.
- The idea has a clear next step or checklist.
- The work should be tracked as execution rather than exploration.

## Steps

1. Review the idea and extract the concrete work to be done.
2. Create a new task document using the task template.
3. Link the task back to the originating idea when useful.
4. Update the idea status to reflect promotion or keep it linked as needed.

## Result

- A task exists for execution.
- The idea is no longer the primary work container.

## Notes

- Do not promote ideas that are still vague or speculative.
- Keep the original idea for context when the history matters.
