# Create Work Log

A work log is created when a task has a meaningful execution attempt, setup, observation, or result to record.

## Purpose

Record what was tried, what happened, and what was learned.

## Conditions

- A task was executed, investigated, or meaningfully adjusted.
- The result is worth preserving for future reference.

## Steps

1. Identify the task or work that was performed.
2. Capture the result, environment, procedure, and any failure details.
3. Save the record as a work log document.
4. Link the work log back to the related task and decision if useful.

## Result

- A durable record of the work exists.
- The task can reference the work log for evidence and context.

## Notes

- Record failures as well as successes.
- Keep the log concise enough to scan later.
