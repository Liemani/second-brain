# second brain과 프로젝트 메모리 분리 결정

second brain과 각 프로젝트 안의 메모리 공간을 어떻게 나눌지에 대한 결정 문서이다.

## Meta

- Created: 2026-06-12

## 결정

second brain은 메인 기록 저장소로 유지한다. 각 프로젝트에는 별도로, 코드와 함께 버전 관리되는 메모리 공간을 둔다.

## 이유

- second brain은 프로젝트를 가로지르는 생각, 작업, 판단을 모으는 중심 저장소로 쓰기 좋다.
- 프로젝트별 메모리는 코드와 가까운 위치에서 함께 버전 관리되는 편이 실제 개발 흐름에 더 잘 맞는다.
- 공통 기록과 프로젝트 내부 맥락을 분리하면, 각 공간의 역할이 더 선명해진다.

## 영향

- 프로젝트 전반을 가로지르는 기록과 운영 구조는 second brain에 둔다.
- 특정 프로젝트 구현과 직접 맞물리는 메모는 해당 프로젝트 저장소 안에 둔다.
- 필요하면 프로젝트 메모에서 second brain 문서로 연결하거나, second brain에서 프로젝트 메모 위치를 참조한다.
