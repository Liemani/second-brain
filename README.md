# Root

루트는 저장소의 전체 구조를 짧게 안내하는 자리입니다.

## Entries

- `README.md`: 루트 구조 설명
- `0_inbox/`: 아직 분류되지 않았거나 빠르게 쌓는 메모
- `1_active/`: 현재 진행 중인 작업과 인덱스
- `2_stable/`: 정리된 기준 문서
- `3_archive/`: 보관 영역

## Start Here

- 현재 작업 인덱스: [1_active/index.md](1_active/index.md)

## Rule

- `3_archive/` 내부는 루트 안내에서 펼치지 않습니다.
