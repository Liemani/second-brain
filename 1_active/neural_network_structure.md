# Neural Network Structure

## Question

어떤 구조의 neural network를 만들지 먼저 정해야 전체 구현 범위가 정리됩니다.

## Options

- 단일 layer perceptron
- 다층 feedforward network
- recurrent structure
- event-driven node network
- fully custom graph structure

## Consider

- node 연결을 고정된 layer로 볼지 그래프로 볼지
- feedback loop를 허용할지
- 시간 개념을 구조에 포함할지
- 실험용 최소 구조를 어디까지로 잡을지
