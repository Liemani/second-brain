# Dream Template

This document contains a copyable template and guidance for creating dream records.
Copy only the fenced block under `## Template` when creating a new record.

## Template

```md
---
updated: YYYY-MM-DD
related_thoughts:
  - "[<thought title>](../thoughts/<thought file>)"
related_ideas:
  - "[<idea title>](../ideas/<idea file>)"
---

# <꿈 제목>

<Short role description>

## Notes

- <꿈 내용>
- <기억나는 장면>
- <느낀 감정>
- <나중에 연결할 만한 해석>
```

## Guide

### What this record is

Dream records capture sleep narratives separately from waking thoughts.

### Important fields

#### updated

- Last meaningful update date. Use `YYYY-MM-DD`.

#### related_thoughts

- Link related thoughts or interpretations when useful.

#### related_ideas

- Link ideas suggested by the dream when useful.

### Notes

- Record raw dream content first.
- Preserve remembered scenes, feelings, and sequence.
- Keep interpretation separate if added later.

### Links

- `thought` can be linked when a dream leads to interpretation.
- `idea` can be linked when a dream suggests a useful direction or concept.
