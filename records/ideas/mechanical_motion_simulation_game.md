# 부품을 직접 만들어 기계 움직임을 시뮬레이션하는 게임

실제 기계 공학적인 움직임을 부품 단위로 직접 설계하고 조립해 시뮬레이션하는 게임 아이디어다.

## Notes

- 기계가 어떻게 움직이는지 단순히 보는 것이 아니라, 부품을 직접 만들어 연결하면서 동작을 이해하는 재미가 핵심이다.
- 기어, 링크, 축, 모터, 마찰, 하중 같은 요소를 조합해 원하는 움직임을 만들어보는 경험을 중심에 둔다.
- 교육용 시뮬레이터와 샌드박스형 게임 사이의 감각을 갖되, 직접 만들어서 시험하는 쪽에 더 무게를 둔다.
