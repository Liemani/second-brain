# Principles

> A project template where humans and AI agents continuously collaborate through shared context.

## Purpose

- 이 템플릿은 사람과 AI가 공유된 문맥을 바탕으로 함께 작업하기 위한 기준을 담는다.
- 구조는 현재의 작업과 관리에 실제로 필요한 만큼만 유지한다.

## Canonical Ownership

- 정보는 한 곳에서만 canonical owner를 가져야 한다.
- 각 문서는 자기 책임만 가진다.
- 설명과 구조는 가능한 한 원본 문서에 남아 있어야 한다.

## Project Layers

- `README.md`는 프로젝트를 소개하고 탐색의 시작점을 제공한다.
- `AGENTS.md`는 온보딩 안내를 담는다.
- `PRINCIPLES.md`는 운영 원칙을 담는다.
- `memory/`는 프로젝트 문맥, 기록, 탐색을 담는다.

## Templates

- 템플릿은 필요한 문맥을 스스로 제공해야 한다.
- 각 템플릿은 무엇을 만들지와 어떻게 만들지를 함께 설명해야 한다.

## Minimal Useful Structure

- 구조는 설명력이 있을 때만 추가한다.
- 실제로 유지 가능한 최소 구조를 우선한다.

## System Evolution

- 원칙은 재사용 가능한 설계 패턴이 발견될 때만 갱신한다.
- 프로젝트는 스스로를 설명할 수 있어야 하며, 그 설명도 함께 진화해야 한다.
