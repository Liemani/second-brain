# Principles

> A reusable project template where onboarding, memory, and raw inputs stay clearly separated.

## Purpose

- 이 템플릿은 새 프로젝트의 시작점이 되는 재사용 가능한 형태를 제공한다.
- 프로젝트 소개, 온보딩, 기억, 원본 입력은 서로 다른 책임을 가진다.

## Canonical Ownership

- `README.md`는 프로젝트를 소개한다.
- `AGENTS.md`는 온보딩을 맡는다.
- `PRINCIPLES.md`는 프로젝트 수준의 원칙을 담는다.
- `memory/`는 프로젝트 문맥과 기억을 담는다.
- `raw/`는 정리되지 않은 입력을 담는다.

## Project Layers

- `README.md`는 프로젝트를 소개한다.
- `AGENTS.md`는 온보딩 부트스트랩을 담는다.
- `PRINCIPLES.md`는 프로젝트 운영 원칙을 담는다.
- `memory/`는 프로젝트 기억과 탐색을 담는다.
- `memory/records/`는 기록 컬렉션을 담는다.
- `raw/`는 원본 입력과 미정리 자료를 담는다.

## Minimal Useful Structure

- 구조는 프로젝트 시작점으로 유지하는 데 필요한 만큼만 둔다.
- 문서는 서로의 책임을 덮어쓰지 않도록 유지한다.
